## 📄 Краткое описание приложения
---
Мобильное приложение для онлайн-магазина одежды.
Позволяет пользователям просматривать каталог товаров, фильтровать по категориям, 
добавлять изделия в избранное и оформлять заказы.

## 🚀 Как собрать проект
---
1. Склонируйте репозиторий:
```bash
   git clone https://github.com/FEIP-FEFU-Mobile-Spring-2026/team-vibe-mobile.git
   ```
2. Перейдите в паппку проекта
   ```bash
   cd <Название проекта>
   ```
3. Откройте проект в Android Studio:
    - Запустите IDE и выберите **File → Open**
    - Укажите путь к папке проекта `team-vibe-mobile`
    - Дождитесь завершения синхронизации Gradle (индикатор в нижней панели)

4. Запустите сборку и установку:
    - Подключите устройство или запустите эмулятор
    - Нажмите кнопку **Run 'app'** (зелёный треугольник ▶️) в верхней панели
    - Или используйте терминал:
```bash
   ./gradlew build
 ```
#### Debug сборка
```bash
   ./gradlew assembleDebug
 ```

### ⚠️ Если ветка не видна после клонирования проекта
**Решение:**
1. Подтянуть все удалённые ветки
    ```bash
    git fetch --all
    ```
2. Создать локальную ветку на основе удалённой и переключиться на неё
    ```bash
    git checkout -b <Название ветки> origin/<Название ветки>
    ```
3. Проверить, что вы в правильной ветке
    ```bash
    git branch --show-current  # должно вывести: <Название ветки>
    ```
